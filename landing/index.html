Features

Industry-grade
prompt engineering.

Everything you need to tame LLM input predictably — running entirely on your hardware.

🧠
Core

AI-Powered Prompt Refiner

Llama 3.5 runs locally via Ollama and transforms any raw input into a structured prompt with extracted role, task, output format, and strict constraints — validated by Pydantic.

POST /refine → RefinedPromptOutput
⚡
Smart

Intelligent Model Router

The Auto mode uses Llama to analyse your task and recommend the best model from your allowed list — with a runner-up and clear reasoning.

POST /suggest-model
🎨
Format

Provider-Native Formatting

Each prompt is formatted specifically for its target — XML tags for Claude, numbered sections for GPT, markdown headings for Gemini, terse specs for DeepSeek.

🔒
Private

Fully Local — Zero Leakage

Your prompts never leave your machine. Llama runs in Ollama, the API runs in FastAPI, and the UI is served locally. No telemetry, no cloud calls.

📐
Strict

Pydantic Schema Enforcement

Every output is typed and validated against RefinedPromptOutput — role, task, format, constraints, and the final prompt are guaranteed to match the schema.

🌐
Universal

19+ Models, 6 Providers

Claude, GPT-5.x, Gemini 3, DeepSeek V3, Grok 3, Copilot — with free/paid tiers, per-model strengths, and smart hallucination guards on model IDs.
